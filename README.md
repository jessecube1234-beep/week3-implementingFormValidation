# week3-implementingFormValidation

## Overview

This project shows how to validate form inputs using HTML 5 and JavaScript

### Features
1. HTML5 validation using attributes like required, minlength, type, min and max
2. Javascript validation for the username input length on the second form

### Files
index.html
main.js
styles.css

### How to Use
1. Open index.html in a browser
2. Try submitting the HTML5 form- uses built in validation
3. Try submitting the Javascript form- with more and less than 5 characters
